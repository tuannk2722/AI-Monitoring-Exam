# 17 — Templates (Mẫu tài liệu)

Chỉ dùng template canonical:

- GitHub issue: `.github/ISSUE_TEMPLATE/task.yml`.
- Pull request: `.github/pull_request_template.md`.
- Task thông thường: `docs/templates/task-template.md`.
- Checkpoint task hiện hành cho Codex: [`.codex/TASK.md`](../.codex/TASK.md), dùng task template và lifecycle theo [AGENTS.md](../AGENTS.md).
- Experiment: `docs/templates/experiment-template.md`.
- Dataset candidate: `docs/templates/dataset-candidate-template.md`.
- ADR: `docs/decisions/ADR-TEMPLATE.md`.

Không sao chép toàn bộ nội dung template vào file này; chỉ cập nhật ở một vị trí canonical.
